# Politique de sécurité

## Versions supportées

| Version | Supportée          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Signaler une vulnérabilité

Signalez toute vulnérabilité par email à **fabien@10dix.fr**, ou via une
[issue GitHub](https://github.com/3tibet/signature-email/issues) si elle ne
présente pas de risque d'exploitation immédiat.

Vous recevrez un accusé de réception sous 72 heures et un point d'avancement
sous 7 jours. Si la vulnérabilité est confirmée, un correctif est publié sur
https://signature.10dix.fr et une nouvelle version taguée dans ce dépôt.

Le générateur fonctionne entièrement côté navigateur : aucune donnée saisie
dans le formulaire n'est transmise à un serveur.
