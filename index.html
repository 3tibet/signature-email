Comment installer votre signature ?

⚠ Images dans Gmail : La fenêtre de rédaction (Nouveau message) bloque les images locales. Pour que photo et logo s'affichent, utilisez Paramètres → Signature (pas la fenêtre de composition) — Gmail héberge alors les images automatiquement. Ou collez une URL externe dans les champs photo/logo ci-dessus (ex: Google Drive, Imgur).
Gmail
⚙ Paramètres → Voir tous les paramètres → Général → Signature → Créer → coller (Ctrl+V)
Outlook
Fichier → Options → Courrier → Signatures → Nouvelle → coller le contenu copié
Apple Mail
Préférences → Signatures → créer → coller avec Ctrl+V
Thunderbird
Paramètres du compte → cocher "HTML" → coller le code source dans le champ signature
🔒 Vos données restent sur votre appareil. Cet outil fonctionne entièrement dans votre navigateur — aucune donnée personnelle n'est collectée, stockée ou transmise.
